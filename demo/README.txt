Willora Gallery 演示（点击运行）
Willora Widgets Gallery — click-to-run Windows demo

1. 双击 Start-Demo.bat（或 WilloraGallery.exe）。
   Double-click Start-Demo.bat or WilloraGallery.exe.

2. 需要 64 位 Windows，以及 Microsoft Visual C++ 可再发行组件（x64）。
   本目录不包含 vc_redist.x64.exe。若缺少 VCRUNTIME140.dll 或 MSVCP140.dll，请安装：
   https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist
   https://aka.ms/vs/17/release/vc_redist.x64.exe

3. 完整说明（许可、包含内容、可选的 opengl32sw.dll）见仓库根目录 README.md：
   https://github.com/abchears/WilloraGallery
